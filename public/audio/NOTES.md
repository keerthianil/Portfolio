# Audio

`coffee-sip.mp3` plays when the mug in the room is clicked or activated. The
file here is a placeholder: filtered brown noise shaped into a swell, kept quiet
on purpose. It reads as a sip at low volume and it is the only sound on the
site.

Replace it with a real recording when there is one. Nothing breaks if the file
is missing: the coffee level still drops and the state is still announced,
because the sound was never the only feedback.
